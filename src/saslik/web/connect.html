How to install and connect
  1. Install Skewer for your platform.
  2. Open the Saslik URL shown above and confirm its certificate fingerprint.
  3. Install the workspace CA only on a test device or test profile.
  4. Select your test application and verify routing; check the tunnel if one is used.
How to set up Android
  1. Install the published Skewer APK.
  2. Confirm the Saslik certificate fingerprint before pairing.
  3. Install the CA as a user certificate when TLS inspection is required.
  4. Use a dedicated test profile; Android applications may choose not to trust user CAs.
