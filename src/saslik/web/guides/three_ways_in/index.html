Three paths

Three ways in. Start with Skewer.

More details · about what you see

  • You have options

    Different access paths suit different networks and applications. Skewer is the most convenient starting point; manual proxy settings and direct routing remain available when you need them.

  • Getting there is not decrypting it

    Routing delivers traffic. To inspect HTTPS, the test application also needs to trust the workspace CA.

02

Why Skewer?

You can do the plumbing. Or bring Skewer.

More details · about what you see

  • Manual configuration can be quick too

    If you know the ropes and already have the proxy address and CA, you can set things up quickly yourself. Skewer brings the same tasks into one place, making setup convenient without having to know every setting in advance.

  • Auto finds the connection for you

    Auto is Skewer’s default connection mode. After pairing, Skewer checks how to reach Saslik: it uses a direct gateway when available, otherwise a tunnel. You can also select Direct or Enforced tunnel yourself.

  • Trust is not universal

    Skewer can help configure supported stores. Apps with their own trust rules or certificate pinning may still refuse inspected HTTPS.

  • Pick the smallest useful experiment

    Open a simple website with a distinctive hostname in your test browser. It will be easy to recognize in the connection list.

03

Explicit proxy

Explicit proxy: bring your own settings.

More details · about what you see

  • Not every app reads the same settings

    Some use operating-system proxy settings, some have their own, and some ignore both. Configuring one browser does not automatically route every app.

  • TCP is not the whole story

    Traditional HTTP CONNECT provides a TCP tunnel. SOCKS5 also defines UDP ASSOCIATE, so “all explicit proxies are TCP-only” would be wrong. UDP needs support from the app, proxy and exposed network path.

  • DNS is another choice

    A SOCKS client can resolve names locally or ask the proxy to do it. Proxying an application does not necessarily proxy its DNS queries.

04

Direct routing

Direct routing: Saslik is your next hop.

More details · about what you see

  • Whole-device experiments can get tricky fast

    A default-route change can affect all applications on your system, not just the one you want to inspect. Skewer lets you select that app and route its traffic into Saslik without turning the whole device into an experiment.

05

Tunnel

Tunnel: bring remote traffic closer.

More details · about what you see

  • A tunnel is not a way around every firewall

    The tunnel needs a reachable endpoint. Saslik allocates UDP ports above 40000 (currently 40001–40255); the network firewall must allow the assigned port.

  • Tunnel down? Your app stays in the test.

    With Enforced tunnel, selected traffic is blocked if the tunnel fails. Your app does not silently escape the test environment through a normal connection.
